Applies to: all engines; all production periods

Description

The boot open motor is operated by:

  • the button on the dashboard;
  • the remote control.

The control unit built into the commands unit on the door controls the operation of the boot lock release: it receives the request to open the boot from the Body Computer or from the control signal from the relevant button on the dashboard., and consequently issues a command to an external relay, located under the dashboard behind the Body Computer.

The boot opening logic is as follows:

  • when the ignition is on, the control button causes the boot to open if the vehicle speed is 0 km/h;
  • with the ignition off, or when one of the doors is opened, the control button operates for a timed period of 3 minutes.

Whenever the control button is pressed, a confirmation beep is issued - via a signal transmitted on the CAN - by the instrument panel buzzer.

If the Body Computer detects that one of the doors or the boot has been left open and the vehicle speed exceeds around 3 Km/h, a buzzer is sounded.

The remote control receiver aerial is connected directly to the Body Computer which contains the electronics of the receiver proper: the remote control is located in the key, on which a specific button controls the boot release (a further two buttons control the door lock and release E3040 CENTRAL LOCKING ). The Body Computer receives the boot open request from the remote control and, with the ignition off, sends the command to the unit on the door.
