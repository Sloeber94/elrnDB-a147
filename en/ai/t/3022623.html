Applies to: all engines; all production periods

When the front fog lamps switch is operated with the side lights on, the front fog lamps do not work.

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect an Examiner to the diagnostic socket

Check that there are no faults in the Body Computer

Check light operation while in active diagnosis mode.

Continue to Step 2

Fog lamp relay error

Checking fog lamp electric circuit/relay

Continue to Step 3

Lights not activated

Check individual lights

Continue to Step 2

2

CHECKING INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and lamps

Continue to Step 3

Left bulb damaged

Change the bulb

Right bulb damaged

Change the bulb

Fault in right front light cluster

Repair or replace front light cluster Op. 5540B75 Right front LIGHT CLUSTER with fog light - R.R .

Fault in left front light cluster

Repair or replace front light cluster Op. 5540B74 Left front LIGHT CLUSTER with fog light - R.R.

3

CHECK FOG LAMP ELECTRIC CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • front fog lamp fuse;
  • fog lights relay;
  • engine compartment control unit supply;
  • connections between Body Computer and engine compartment control unit;
  • connections between engine compartment control unit and bulbs;
  • connections between Body Computer and fog lights switch;
  • bulb earth : See E2030 FOG LIGHTS

Continue to Step 4

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections: See E2030 FOG LIGHTS

4

CHECKING FOG LAMP SWITCH

All OK

Problems met

Operation

Check the operation of the fog lamp switch See E2030 FOG LIGHTS

Continue to Step 5

Fog lamp switch defective

Replace the control panel Op. 5505A24 w/l and service switch mount - r+r

5

CHECKING BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer is working properly, in particular the front fog lamps control function

Continue to Step 6

Device not working

Replace the Body Computer Op. 5505A32 body computer - r r

6

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
