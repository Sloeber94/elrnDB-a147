Applies to: all engines; all production periods

Under any conditions, the Cruise Control system controls do not work

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket.

Check that there are no faults in the engine management control unit

Continue to Step 2

An error is detected in the control unit

Proceed according to the instructions of the diagnostic equipment

Lack of dialogue with the control unit

Restore the connection between the management control unit and diagnostic connector: See E5060 CRUISE CONTROL

2

CHECK CRUISE CONTROL SELECTOR

All OK

Problems met

Operation

Check that the Cruise Control contacts are working:

Continue to Step 3

Lack of continuity

Replace the stalk unit lever with built-in Cruise Control system control Op. 5580A10 cruise control lever assembly - r+r

3

SUPPLY CHECK

All OK

Problems met

Operation

With the ignition and Cruise Control on, check that there is a voltage signal from the Cruise Control system control to the engine management control unit: See E5060 CRUISE CONTROL

Continue to Step 4

No voltage found

Restore the connections: See E5060 CRUISE CONTROL

4

CHECK ON CONNECTIONS

All OK

Problems met

Operation

Check the electrical continuity of the wiring between junction unit, ignition switch, engine management unit and cruise control system control: See E5060 CRUISE CONTROL

Continue to Step 5

Lack of continuity

Restore the connections: See E5060 CRUISE CONTROL

5

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists: control unit faulty

Replace the engine management control unit Op. 1056B82 injection/ignition system e.c.u. (one) - r + r

Search for the fault starting from another symptom'
