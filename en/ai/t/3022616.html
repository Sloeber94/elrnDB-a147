I06 MAIN BEAM HEADLAMPS NOT WORKING

Applies to: all engines; all production periods

With the dipped headlamps switched on (stable position) or in the flashing mode, when the stalk unit ring nut is operated, the main beam headlamps do not work

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner equipment to the diagnostic socket.

Verify:

  • that there are no faults in the Body Computer
  • through the active diagnosis, the operation of the lights.

Continue to Step 3

Error – ( main beam headlamps relay)

Check - main beam headlamps relay/main beam headlamps electrical circuit.

Continue to Step 3

Lights not activated

Check individual lights

Continue to Step 2

2

CHECKING INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 3

Bulbs damaged

Replace bulbs

Fault in right front light cluster

Repair or replace front light cluster Op. 5540B75 Right front LIGHT CLUSTER with fog light - R.R .

Fault in left front light cluster

Repair or replace front light cluster Op. 5540B74 Left front LIGHT CLUSTER with fog light - R.R.

3

MAIN BEAM HEADLAMPS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • left and right main beam headlamp fuses;
  • main beam headlamps relay feed;
  • connection between steering column switch unit and Body Computer;
  • connection between Body Computer and engine compartment control unit;
  • connections between engine compartment control unit and bulbs; bulbs earth : See E2012 MAIN BEAM HEADLAMPS

Continue to Step 4

Blown fuses

Replace the fuses, then search for the cause of the problem

Connections not correct

Restore the connections: See E2012 MAIN BEAM HEADLAMPS

Bulb earth faulty

Restore the earth to the bulbs : See E2012 MAIN BEAM HEADLAMPS

4

CHECKING STEERING COLUMN SWITCH UNIT

All OK

Problems met

Operation

Check that the steering column switch unit is working properly: See E2012 MAIN BEAM HEADLAMPS

Continue to Step 5

Stalk unit faulty

Replace the stalk unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

5

CHECKING BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer is supplied properly

Check that when an earth signal from stalk unit to Body is activated, an earth signal is emitted from the Body to drive the dipped beam headlamps relay

Continue to Step 6

Incorrect supply

Restore power supply See E2012 MAIN BEAM HEADLAMPS

Body Computer faulty

Replace the Body Computer Op. 5505A32 body computer - r r

6

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
