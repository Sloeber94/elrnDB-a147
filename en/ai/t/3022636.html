J03 SCREEN WASHER NOT WORKING

Applies to: all engines; all production periods

When the lever on the right of the steering wheel is pulled towards the latter, the windscreen washer function does not work properly.

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Carry out a preliminary check on the fluid level in the reservoir; also make sure that it is not leaking.

Check that when the lever on the right of the steering wheel is operated, the windscreen wipers work properly.

Check that the jets are not obstructed by ice or dirt

Continue to Step 1

Mixture level too low

Top up the level Op. 5050A14 reservoir plug (in engine bay) or windscreen washer fluid level sensor - check and top up if necessary

Reservoir damaged

Replace the reservoir Op. 5050A10 windscreen washer fluid reservoir (in engine bay) - r+r

The windscreen wipers are not working

See table J01 WINDSCREEN/REARSCREEN WASHERS NOT WORKING

1

ELECTRIC WINDSCREEN WASHER PUMP SUPPLY CHECK

All OK

Problems met

Operation

Check the connection between the steering column switch unit, windscreen wiper control unit, junction unit, electric windscreen washer pump : See E3020 WINDSCREEN WASH/WIPE

Continue to Step 2

Connection broken

Restore the windscreen washer connections : See E3020 WINDSCREEN WASH/WIPE

2

ELECTRIC WINDSCREEN WASHER PUMP CHECK

All OK

Problems met

Operation

Check the operation of the electric windscreen washer pump

Continue to Step 3

Electric pump faulty

Replace the electric windscreen washer pump Op. 5050B22 front and rear screen washer pump - r+r

3

STEERING COLUMN SWITCH UNIT CHECK

All OK

Problems met

Operation

Check that the steering column switch unit is working properly

Continue to Step 4

Steering column switch unit not working

Replace the steering column switch unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

4

CHECK WIPER CONTROL UNIT

All OK

Problems met

Operation

Make sure that the windscreen wiper control unit is working properly

Continue to Step 5

Windscreen wiper control unit damaged

Replace the windscreen wiper motor control unit Op. 5050B38 windscreen wiper assembly - r+r or repair

5

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists
