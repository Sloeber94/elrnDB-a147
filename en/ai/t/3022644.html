J33 AUTOMATIC DEMISTING NOT WORKING

Applies to: all engines; all production periods

With the climate control system on, the automatic demister does not work (In systems where there is the 'automatic demister' function with the windscreen misted up and the climate control system on automatic operation, the control unit acts by increasing the fan speed - orientating the air distribution to the windscreen and sides)

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the equipment (Examiner or Examiner plus) to the diagnostic socket and check:

  • that there are no errors in the climate control system control unit

Continue to Step 2

There are faults in the control unit

Continue according to the instructions for the diagnostic equipment

2

CHECK ON SENSOR SUPPLY

All OK

Problems met

Operation

Check, in order:

  • sensor supply fuse
  • sensor earth and supply
  • connection between sensor and climate control unit See E6020 AIR CONDITIONING

Continue to Step 3

Fuse blown

Replace the fuse and search for the cause of the short circuit

No sensor earth/supply

Restore the correct connections

Connection broken

Restore the correct connections

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Replace the climate control system control unit Op. 5040D15 control unit with automatic duel zone air conditioner knobs and buttons r r

Search for the fault starting from another symptom'
