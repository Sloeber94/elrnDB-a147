Applies to: engines: 1.9 JTD 16V; all production periods

The coolant consumption is high (it needs topping up frequently)

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

First visually inspect the cooling system to check that there are no coolant leaks.

Continue to Step 1

There are leaks

Continue as instructed in the Table See table X10 ENGINE COOLANT LEAKS

1

COOLING SYSTEM LEAKAGE CHECK

All OK

Problems met

Operation

Connect the test equipment replacing the expansion tank cap, pressurize the system to a value of slightly below 1.4 bar and check that the pressure remains at the recommended value for a few minutes and that there are no visible leaks.

Continue to Step 3

Fall in pressure detected with no visible leaks

Continue to Step 2

Fall in pressure detected with visible leaks

Continue as instructed in the Table See table X10 ENGINE COOLANT LEAKS

2

CHECKING CYLINDER HEAD

All OK

Problems met

Operation

Remove the head.

Check:

  • That the planarity of the cylinder head plane is correct
  • That the planarity of the cylinder head support surface on the cylinder block is correct;

Continue to Step 3

Cylinder head plane defective

Regrind the cylinder head plane

Cylinder block/crankcase plane defective

Regrind the cylinder block/crankcase plane

Planes correct, head gasket faulty

Replace the cylinder head gasket

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis
