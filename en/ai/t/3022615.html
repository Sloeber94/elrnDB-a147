I05 DIPPED HEADLAMPS NOT WORKING

Path

fault diagnosis table (symptom -> numbered test steps)
Applies to

Interactive page

Applies to: all engines; all production periods

When the steering column switch unit ring nut is operated with the ignition ON, the dipped headlamps do not work

The dipped headlamps do not work if the main beam headlamps and the fog lights are on at the same time

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner equipment to the diagnostic socket.

Verify:

  • that there are no faults in the Body Computer
  • through the active diagnosis, the operation of the lights.

Continue to Step 3

Error – ( dipped headlamps maintenance relay at CVM)

Check dipped headlamps maintenance relay/dipped headlamps electrical circuit

Continue to Step 3

Lights not activated

Check individual lights

Continue to Step 2

2

CHECKING INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 3

Bulbs damaged

Replace bulbs

Fault in right front light cluster

Repair or replace front light cluster Op. 5540B75 Right front LIGHT CLUSTER with fog light - R.R .

Fault in left front light cluster

Repair or replace front light cluster Op. 5540B74 Left front LIGHT CLUSTER with fog light - R.R.

3

DIPPED HEADLAMPS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • right and left dipped headlamp fuses;
  • dipped headlamp maintenance relay;
  • connections between steering column switch unit and Body Computer;
  • connections between Body Computer and dashboard control unit;
  • connections between dashboard control unit and bulbs;
  • bulb earths : See E2011 DIPPED HEADLAMPS

Continue to Step 4

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections: See E2011 DIPPED HEADLAMPS

4

CHECKING STEERING COLUMN SWITCH UNIT

All OK

Problems met

Operation

Check that the stalk unit is working properly; in particular check the side lights switch Characteristic of working principle 5550 MANOEUVRING AND WARNING SIGNALS

Continue to Step 5

Steering column switch unit not working properly

Replace the stalk unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

5

CHECKING BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer is supplied properly

Check that when an earth signal from stalk unit to Body is activated, an earth signal is emitted from the Body to drive the dipped beam headlamps relay: See E2011 DIPPED HEADLAMPS

Continue to Step 6

Body Computer supply incorrect

Restore the correct supply See E2011 DIPPED HEADLAMPS

Body Computer faulty

Replace the Body Computer Op. 5505A32 body computer - r r

6

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
