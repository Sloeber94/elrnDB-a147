Applies to: all engines; all production periods

After deactivating the Cruise Control system by pressing the brake/clutch pedal, using the 'RESUME' button on the Cruise Control, the speed set previously is not restored.

Results of the tests

1

CHECK ON RESUME COMMAND

All OK

Problems met

Operation

Check that the Cruise Control contacts work properly in the RESUME position

Continue to Step 2

Lack of continuity

Replace stalk unit lever with built-in Cruise Control system control Op. 5580A10 cruise control lever assembly - r+r

2

CHECK CONNECTIONS TO ENGINE MANAGEMENT CONTROL UNIT

All OK

Problems met

Operation

With the ignition and Cruise Control knob set to 'ON' and 'RESUME', check that there is a voltage signal from the Cruise Control system control to the engine management control unit: See E5060 CRUISE CONTROL

Continue to Step 3

No voltage found

Restore the connections: See E5060 CRUISE CONTROL

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

The fault persists: control unit faulty

Replace the engine management control unit Op. 1056B82 injection/ignition system e.c.u. (one) - r + r

Search for the fault starting from another symptom'
