Applies to: all engines; all production periods

When the alarm is activated, the volumetric surveillance does not work

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Volumetric surveillance can be excluded voluntarily from the operation of the system: wiring diagram See E7015 ALARM

Connect the diagnostic equipment (Examiner or SDC) to the diagnostic socket and check whether there are faults in the CAN network

Continue to Step 2

Faults present on the CAN network

Repair the connections on the interested nodes

2

CHECK VOLUMETRIC SENSORS

All OK

Problems met

Operation

Check, in order:

  • Operation of volumetric sensors
  • Connections between sensors and Body Computer: wiring diagram See E7015 ALARM

Continue to Step 3

Sensor faulty

Replace sensors Op. 5580E22 Anti-theft device VOLUMETRIC SENSORS - R.R. after checking electrical circuit

Connections broken

Renew the connections: wiring diagram See E7015 ALARM

3

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
