Applies to: all engines; all production periods; only with equipment: Radiotelefono

Description

In the version with integrated CONNECT radio-telephone-navigator, the telephone (GSM module and SIM-CARD reader) is built into the unit.

in the version without integrated radio-telephone-navigator, the car can be fitted with the preparation for the installation of a mobile phone E3580 PREPARATION FOR CELLULAR TELEPHONE .

This system includes:

  • GSM module and SIM-CARD reader integrated in the radio-telephone-navigator;
  • hands-free function via the radio speakers;
  • microphone located in the front courtesy light;
  • outside aerial.

An additional outside telephone receiver can be fitted, on request, which switches automatically to the radio-telephone system.

The integrated radio-telephone-navigator is a node of the CAN network through which it exchanges information with the Body Computer and other electronic units.

The commands of the telephone function are grouped together on a conventional telephone keyboard (12 buttons), with in addition dedicated keys for emergency call.

The commands are displayed on the integrated radio-telephone-navigator display.

Some versions have a set of buttons located on the steering wheel: these, in addition to the radio controls, allow commands to be sent for the telephone function.

There is also the 'voice recognition' function: this is an internal voice recognition module which acquires the commands received from the microphone and interprets them, sending them to the telephone unit proper.

Some commands made by the user while using the telephone are repeated on the instrument panel ('HIGH' version).

The fishpole antenna is mounted at the rear of the roof: this is a two-function aerial with two cables: one is the actual radio aerial, and one is the telephone cable with dual reception band (GSM-ETACS at 900 Hz and D.C.S. at 1800 Hz).

If the navigator is also installed E4091 CONNECT , the aerial has three functions (radio/GSM/GPS).

For more details on the operation of the telephone 5580N intergrated control system (ics) panel .
