Applies to: all engines; all production periods

The Cruise Control system does not reduce the speed when the ring nut is turned to " – "

Results of the tests

1

SELECTOR OPERATION CHECK

All OK

Problems met

Operation

Check that the Cruise Control contacts work properly in the Set- position:

Continue to Step 2

Lack of continuity

Replace the steering column switch unit lever with the Cruise Control lever incoroporated Op. 5580A10 cruise control lever assembly - r+r

2

SUPPLY CHECK

All OK

Problems met

Operation

With the ignition ON and the Cruise Control ON and at '-', check that there is a voltage signal from the Cruise Control system to the engine management control unit: See E5060 CRUISE CONTROL

Continue to Step 3

No voltage found

Restore the connections: See E5060 CRUISE CONTROL

3

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present

The fault persists: control unit defective

Replace the engine management control unit Op. 1056B82 injection/ignition system e.c.u. (one) - r + r

Search for the fault starting from another symptom'
