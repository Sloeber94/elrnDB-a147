B10 ENGINE DOES NOT START / UNDER NO CIRCUMSTANCES

Applies to: engines: 1.6 TS, 2.0 TS; all production periods

The engine does not start. When the key is turned, the instruments light up, the starter motor turns, but the engine will not start.

The MIL warning light should come on with the ignition on and go out once the engine has started;

The CODE warning light only comes on if there is a fault.

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Turn the key to the ON position and check that the I.E and CODE lights come on for the start-up test

The I.E light should come on for about 4 seconds and then switch off, while the CODE light should come on for about 1 second and the switch off.

Check

  • that the inertia switch has not been operated;
  • the state of the spark plugs and leads;
  • that there are no obstructions in the catalytic converter;
  • that there is no water in the fuel
