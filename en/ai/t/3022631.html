Applies to: all engines; all production periods

When operated with the dipped beam headlamps on, the headlamp adjustment knob does not work If the dipped beam headlamps do not work either, first I05 DIPPED HEADLAMPS NOT WORKING

Results of the tests

1

CHECK THE HEADLAMP ALIGNMENT CORRECTOR ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Verify:

  • connection between left control panel and NQS;
  • left control panel earth;
  • connection between dashboard control unit and headlamp alignment motors;
  • connection between dashboard control unit and instrument panel;
  • headlamp alignment motor and headlamp alignment control earth See E3080 HEADLAMP AGLINMENT CORRECTOR

Continue to Step 2

Connections not correct

Restore the connections See E3080 HEADLAMP AGLINMENT CORRECTOR

Earths defective

Restore the earth contacts : See E3080 HEADLAMP AGLINMENT CORRECTOR

2

CHECK THE HEADLAMP ALIGNMENT CONTROL

All OK

Problems met

Operation

Check the operation of the headlamp alignment control device : See E3080 HEADLAMP AGLINMENT CORRECTOR

Continue to Step 3

Headlamp adjuster faulty

Replace the left control panel Op. 5560B56 TRIM with SWITCHES/BUTTONS FOR MULTIFUNCTION DISPLAY AND HEADLAMP alignment ADJUSTMENT - R.R.

Defective instrument panel

Replace instrument panel Op. 5560B11 analogue control panel - r+r or replace

3

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
