Applies to: all engines; all production periods

When reverse gear is engaged with the engine started, the buzzer does not work.

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner to the diagnostic socket.

Verify:

  • that there are no errors in the control unit
  • the operation of the buzzer in active diganosis

Continue to Step 2

Buzzer error

Continue to Step 2

2

BUZZER ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • connections between buzzer and SELESPEED control unit;
  • connections between DASHBOARD control unit and buzzer : See E7051 ROBOTIZED GEARBOX

Continue to Step 3

Connections not correct

Restore the correct connections

Buzzer defective

Replace buzzer

3

CORRECT OPERATION CHECK

All OK

Problems met

Operation

Check that the fault is no longer present
