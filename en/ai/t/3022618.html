Applies to: all engines; all production periods

With the ignition on, when the lever on the steering column switch is raised or lowered or when the appropriate button is pressed, the direction indicators/hazard warning lights work but flash irregularly

If one of the bulbs is not working, the intermittent flashing of the others is affected: see also Table l10

Results of the tests

1

CHECKING BULBS

All OK

Problems met

Operation

Check the condition of the bulbs and that the rating is correct.

Continue to Step 2

Front bulb rating incorrect

Change the bulb Op. 5550C30 l/h or r/h front turn signal (one) - r+r

Rear bulb rating incorrect

Change the bulb Op. 5540A56 dipped/main beam electrical wiring - check component operation, line continuity and repair contacts - includes relay replacement if necessary

Side repeater rating incorrect

Replace the side repeater Op. 5550C22 l/h or r/h side flasher (one) - r+r

2

CHECK DIRECTION INDICATORS/HAZARD LIGHTS ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • connections between stalk unit and Body Computer
  • connections between the CENTRE CONTROL PANEL and the Body Computer;
  • connections between Body Computer and bulbs;
  • bulb earths: See E2020 DIRECTION INDICATORS / HAZARD WARNING LIGHTS - Description

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections: See E7015 ALARM

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
