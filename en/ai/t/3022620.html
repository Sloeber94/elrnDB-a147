Applies to: all engines; all production periods

When the brake pedal is pressed with the ignition ON, the brake lights do not work. If this fault is not signalled by the special icon in the Display module see also Table l30

Results of the tests

1

CHECKING WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect an Examiner to the diagnostic socket

Check that there are no faults in the Body Computer

Continue to Step 2

Brake lights faulty.

Check individual lights

Continue to Step 2

2

CHECKING INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition/correct rating of the individual bulbs and the bulb holder assembly

Continue to Step 3

Bulbs damaged/unsuitable

Replace bulbs Op. 5540A56 dipped/main beam electrical wiring - check component operation, line continuity and repair contacts - includes relay replacement if necessary

Bulb holder assembly faulty

Repair or replace the rear lights cluster Op. 5540A56 dipped/main beam electrical wiring - check component operation, line continuity and repair contacts - includes relay replacement if necessary

3

CHECK BRAKE LIGHTS ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • stop lights fuse
  • connection between dashboard control unit, Body Computer and brake pedal switch;
  • connections between Body Computer and bulbs : See E2021 BRAKE LIGHTS - Description

Continue to Step 4

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections: See E2021 BRAKE LIGHTS - Description

4

CHECK ON BRAKE PEDAL SWITCH

All OK

Problems met

Operation

Check that the brake pedal switch is fitted correctly and working See E2021 BRAKE LIGHTS - Description

Continue to Step 5

Switch fastening / adjustment incorrect

Adjust the switch

Brake pedal switch faulty

Replace the switch Op. 5550D10 brake light switch - r+r

5

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
