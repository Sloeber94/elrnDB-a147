Applies to: all engines; all production periods

The engine management control unit warning light remains on. The CODE warning light comes on and goes out on the version with low line instruments, while it stays off on versions with high line instruments.

The CODE warning light going out (not coming on in high line versions) means that the dialogue between the two control units has gone well.
