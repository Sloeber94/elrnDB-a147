J01 WINDSCREEN/REARSCREEN WASHERS NOT WORKING

Applies to: all engines; all production periods

With the ignition key in the ON position, when the lever on the right of the steering wheel is operated, the windscreen wash/wipe does not work properly.

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check that all the windscreen wash/wipe steering column switch unit functions are working

Continue to Step 1

Only the windscreen wipers are not working

See table J02 WINDSCREEN WIPERS NOT WORKING

The windscreen washer is not working

See table J03 SCREEN WASHER NOT WORKING

Nothing is working

Continue to Step 1

1

WINDSCREEN WIPER ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • windscreen wiper fuse
  • steering column switch unit relay feed See E3020 WINDSCREEN WASH/WIPE

Continue to Step 2

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore the connections: See E3020 WINDSCREEN WASH/WIPE

2

CONTROL UNIT CHECK

All OK

Problems met

Operation

Check that the electronic control device is working properly and, in particular, that the pins are not oxidized or distorted See E3020 WINDSCREEN WASH/WIPE

Continue to Step 3

Control unit faulty

Replace the windscreen wiper control unit Op. 5050B38 windscreen wiper assembly - r+r or repair

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
